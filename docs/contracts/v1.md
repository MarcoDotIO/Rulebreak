## Semantics

1. **Schema version** is literal `1` on all core records.
2. **Authority** for `actorId` / `campaignId` / tokens / paths / fixture mode comes only from the trusted binding. Explorer tool args are parsed with `parseExplorerToolArgs`, which rejects those fields.
3. **World state** stores item locations as an occurrence list (player or escrow), so duplicated locations remain representable for the faulty fixture (AC-01/AC-02).
4. **Action outcomes** distinguish `accepted`, `domain_rejected`, `policy_denied`, `transport_failure`, and `target_error`. Lifecycle legality is a game concern; transport must still deliver well-formed illegal attempts to the target.
5. **Rule pack** `rulebreak-trade-v1` / `1.0.0` includes INV-001–INV-005. INV-006 is P1 and must not be silently added to P0 packs.
6. **Findings** use `candidate` → `confirmed` only via successful independent replay (product confirmation rule). Modes are `live` | `scripted` | `recorded`.
7. **Events** carry operational timestamps; domain determinism uses `virtualClock` / recorded logical order, not wall clock.
8. **Target vs verifier:** these schemas do not embed mutation handlers. Economy mutation lives in `@rulebreak/economy` (RB-006); predicates in the verifier package (RB-007).
